How I work

I find a problem, I understand it, and I build something to fix it. Before any of that, I check that the problem is the one that was described. Often there is a simpler way of doing the job, and sometimes it is one the people doing it have stopped seeing because it has always been done that way.

Nobody is doing it wrong. The way something is done usually made sense when it started. The only question is whether there is a better way now.
